API

Read-only JSON and CSV. No key, no rate limit, same data the dashboard draws from.

Filters

These apply to /api/detections, /api/export/detections.csv and /api/export/detections.geojson identically — the server reuses one filter implementation, so an export always matches the screen it was taken from.

ParameterAccepts
labelComma-separated: persistent_industrial_source, industrial_fire, flare_signature, agricultural_burning, insufficient_evidence
sourcesComma-separated registry keys: osm, wri, gem, eog. Keeps detections corroborated by any of them.
riskCritical, High, Moderate, Low
temp_classflare_like, furnace_like, mixed, biomass_like, smouldering, unknown
min_scoreFloat 0–1, minimum risk_score
min_fusionFloat 0–1, minimum anomaly_probability
from, toYYYY-MM-DD, inclusive
bboxlon_min,lat_min,lon_max,lat_max
qSubstring match on the matched facility name

Endpoints

GET/api/detections try it

Scored detections, filtered. Returns the columns the map and feed use; the CSV export returns all of them.

GET/api/detection/<detection_id>

One detection, every column, with contributions already parsed into an array.

GET/api/clusters try it

Spatio-temporal clusters: centroid, span, dominant class, dominant combustion regime and which registries confirm them.

GET/api/facilities try it

The cross-referenced facility registry, one row per real-world site. Optional source and bbox; limit defaults to 4000.

GET/api/sources try it

Per-registry status, record counts, licensing and how many detections each one corroborates. A registry that failed to load reports unavailable and why.

GET/api/stats try it

Snapshot id, date window, per-class counts, method version and the running build.

Exports

GET/api/export/detections.csv try it

Every column, filtered. Filename carries the snapshot id.

GET/api/export/detections.geojson

The same rows as a FeatureCollection, for QGIS or ArcGIS.

GET/api/export/clusters.csv

Cluster summaries.

GET/api/export/facilities.csv

The facility registry. Optional source.

GET/api/export/site/<facility_uid>.csv

Every detection attributed to one site — the investigation packet for a single facility.

Example

curl "http://localhost:5000/api/export/detections.csv?label=persistent_industrial_source&sources=gem,wri&min_score=0.5" -o sites.csv

Persistent industrial sources confirmed by GEM or WRI, priority 0.5 and above.

Licensing travels with the data: OSM is ODbL, WRI and GEM are CC BY 4.0. /api/sources returns the exact attribution string for each.
