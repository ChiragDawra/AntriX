What this does and does not measure

SATAT has no field-verified ground truth: nobody has visited these coordinates to confirm what was burning. Claiming an accuracy figure against truth would therefore be an invention. What can be measured is whether the thermal physics and timing alone can predict something they were never shown — whether a detection sits on a site that two or more independent registries agree exists. That is the number below.

Sub-pixel retrieval coverage

The bi-spectral solve returns a temperature only where the observation constrains one. Reporting a number for every pixel would be easy and wrong: below, the honest breakdown.

{% set total = validation.detections %} {% for status, count in validation.retrieval_status.items() %} {% endfor %}
StatusDetections
{{ status }} {{ count }}
{{ (count / total * 100)|round(1) }}%
Two limits worth stating before anyone asks. FIRMS publishes the two I-band channels; NOAA EOG's Nightfire, which catalogues flares for a living, uses several short-wave M-bands that constrain high temperatures far better. And VIIRS I4 saturates at 367 K, above which the retrieval returns a floor rather than a value. Both mean the very hottest sources are the ones SATAT is least able to pin down from this feed — so a snapshot can legitimately contain zero flare_signature detections. That is the honest answer, not a broken feature.
